## v1.3.3

Metadata title fix plus CI/docs housekeeping.

### Fixed
- **Saving no longer discards a user-edited Title**: the "blank the Title when
  it matches the Series" normalization was removed from the client and both
  metadata APIs — what you type is what gets saved.
- **Viewer reflects the saved title immediately**: the title and subtitle in
  the reader update as soon as the save completes, no reload needed.

### Maintenance
- Docker Hub images are now published directly by the Docker workflow; the
  separate sync workflow was removed as redundant.
- npm dependency caching enabled in the publish workflows; docs-only pushes
  skip Docker image rebuilds.
- README and wiki now cross-link the GVE Now companion editor.

All changes passed the full test suite (71 suites / 531 tests) before release.
